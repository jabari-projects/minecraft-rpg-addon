RPG Classes and Subclasses is a Minecraft Bedrock add-on that turns your survival game mode into a class-driven RPG experience. Players can utilize four primary classes—Vampire, Werewolf, Banshee, and Human—with five combat subclasses, unlocking XP-gated abilities, morphs, summons, cooldowns, and specialized equipment.

Built with JSON behavior/resource packs, JavaScript via the Bedrock Script API, custom UI, entity AI, armor effects, and Blockbench-authored models, textures, attachables, and animations, the project adds fantasy to a some-what grounded game.

Its layered code, supernatural resource systems, custom morphs, and owner-controlled AI summons makes it one of the most complicated coding projects I've done.
