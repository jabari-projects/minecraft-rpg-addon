RPG Classes and Subclasses is a Minecraft Bedrock add-on that transforms survival gameplay into a persistent, class-driven RPG experience. Players combine four primary identities—Vampire, Werewolf, Banshee, and Human—with five combat subclasses, unlocking XP-gated abilities, morphs, summons, cooldowns, and specialized equipment.

Built with JSON behavior/resource packs, JavaScript via the Bedrock Script API, custom UI, entity AI, armor effects, and Blockbench-authored models, textures, attachables, and animations, the project delivers a cohesive gameplay and technical-art pipeline.

Its layered buildcraft, supernatural resource systems, custom morphs, and owner-aware AI summons make it one of the most ambitious Bedrock RPG systems in development.
